# Contributing

Bug reports, questions and ideas are very welcome, so please [open an issue](https://github.com/Krelborn/markdown-review/issues/new/choose). To report a vulnerability, follow [SECURITY.md](SECURITY.md) instead.

I'm not accepting pull requests. Markdown Review is a small project I maintain in my spare time, and for now I want to keep its design in one place. If you have a fix in mind, describe it in an issue and I'll take it from there.

To build and test it yourself, see [Build from source](README.md#build-from-source) in the README, and [AGENTS.md](AGENTS.md) for the commands and the layout of the code.
